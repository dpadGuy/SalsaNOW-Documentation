import Shot from '../../../components/Shot.astro';

If your gamepad doesn't wanna connect at all, turn on **Steam Input**. It is off by default, and turning it on might help. Start a new session after you change it.

<Steps>

1. Open the Start menu and choose **SalsaNOW Settings**.

   <Shot
   	src="/images/gamepad-start-menu.png"
   	alt="Start menu with SalsaNOW Settings highlighted"
   	caption="SalsaNOW Settings in the Start menu"
   />

2. Open **Apps**, then **Startup**.

   <Shot
   	src="/images/gamepad-settings-home.png"
   	alt="SalsaNOW Settings home page with Apps in the sidebar"
   	caption="Apps is in the sidebar"
   />

   <Shot
   	src="/images/gamepad-apps.png"
   	alt="Apps page with Startup highlighted"
   	caption="Open Startup"
   />

3. Turn on **Steam Input**.

   <Shot
   	src="/images/gamepad-steam-input-off.png"
   	alt="Startup page with Steam Input switched off and highlighted"
   	caption="Steam Input is off by default"
   />

   <Shot
   	src="/images/gamepad-steam-input-on.png"
   	alt="Startup page with Steam Input switched on"
   	caption="Steam Input is on"
   />

4. Start a new GeForce NOW session. Steam Input takes effect then, not in the session you are already in.

</Steps>
