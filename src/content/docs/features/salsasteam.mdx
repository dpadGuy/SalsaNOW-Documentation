SalsaSteam is a 64-bit Steam client. Use it for the latest Steam features, and for games that need 64-bit Steam to run. That includes Deadlock, Counter-Strike 2, Denuvo games and much more.

By default the NVIDIA 32-bit Steam client is provided for compatibility reasons.

<Steps>

1. Open the Start menu and choose **SalsaNOW Settings**.

   <Shot
   	src="/images/start-menu-settings.png"
   	alt="Start menu with SalsaNOW Settings highlighted"
   	caption="SalsaNOW Settings in the Start menu"
   />

2. Open **Apps**, then **Startup**.

   <Shot
   	src="/images/salsasteam-settings-home.jpg"
   	alt="SalsaNOW Settings home with Apps highlighted"
   	caption="Apps is in the sidebar"
   />

   <Shot
   	src="/images/salsasteam-apps.jpg"
   	alt="Apps page with Startup highlighted"
   	caption="Open Startup"
   />

3. Turn on **64-bit Steam (SalsaSteam)**. SalsaNOW then uses the 64-bit client by default.

   <Shot
   	src="/images/salsasteam-off.jpg"
   	alt="Startup page with 64-bit Steam switched off"
   	caption="64-bit Steam is off until you switch it on"
   />

   <Shot
   	src="/images/salsasteam-on.jpg"
   	alt="Startup page with 64-bit Steam switched on"
   	caption="SalsaSteam is on"
   />

4. Start a new GeForce NOW session. SalsaSteam takes effect then, not in the session you are already in.

</Steps>

## This session only

The desktop also has a **SalsaSteam 64-bit** icon. Double-click it to open the 64-bit client in the session you are in now.

That does not change the default. The next session still uses whatever **64-bit Steam (SalsaSteam)** is set to in SalsaNOW Settings.
