---
title: Keyboard shortcuts
description: The keys SalsaNOW assigns for common Windows shortcuts inside a session.
tableOfContents: false
---

Press the key in the last column while you are in the session.

| Action | Usual shortcut | Inside the session |
| --- | --- | --- |
| Close the window | <kbd>Alt</kbd> + <kbd>F4</kbd> | <kbd>Ctrl</kbd> + <kbd>F4</kbd> |
| Show the desktop | <kbd>Win</kbd> + <kbd>D</kbd> | <kbd>Ctrl</kbd> + <kbd>L</kbd> |
| Switch windows | <kbd>Alt</kbd> + <kbd>Tab</kbd> | <kbd>Ctrl</kbd> + <kbd>Tab</kbd> |
| Open the Start menu | <kbd>Win</kbd> | <kbd>Ctrl</kbd> + <kbd>Win</kbd> |

PowerShell is covered in [Commands](/commands/).
