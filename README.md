# SalsaNOW documentation

Docs for [SalsaNOW](https://github.com/dpadGuy/SalsaNOW), published at <https://documentation.salsanowfiles.work>.

The site is an [Astro Starlight](https://starlight.astro.build/) project. Pages live in `src/content/docs/`.

## Preview locally

Install [Node.js 22](https://nodejs.org/) or newer, then:

```sh
npm install
npm run dev
```

## Publish

Pushes to `main` build the site and deploy the `dist` folder to the `gh-pages` branch. GitHub Pages should keep using that branch, with the custom domain `documentation.salsanowfiles.work`.
